Windows → WSL:
    C:\                      →  /mnt/c/
    C:\Users\YourName\       →  /mnt/c/Users/YourName/

WSL → Windows:
    /home/username/          →  \\wsl$\Ubuntu\home\username\
    ~/projects/BiYeSheji/    →  \\wsl$\Ubuntu\home\username\
                                projects\BiYeSheji\

Q: WSL未安装？
A: PowerShell (管理员) → wsl --install

Q: Python未安装？
A: sudo apt update && sudo apt install python3 python3-pip -y

Q: 权限错误？
A: chmod +x *.py

Q: Git克隆失败？
A: 检查网络，使用HTTPS而不是SSH

Q: 运行很慢？
A: 确保项目在WSL本地（~/projects/）而不是/mnt/c/

详细解答请查看：WSL项目复制指南.md
