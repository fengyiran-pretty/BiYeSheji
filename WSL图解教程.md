### 详细步骤

#### 步骤1: 打开WSL

```
Windows桌面
    ↓
按下 Win键
    ↓
搜索 "WSL" 或 "Ubuntu"
    ↓
点击打开
    ↓
出现黑色终端窗口
```

#### 步骤2: 创建项目目录并克隆

```bash
# 命令1: 进入或创建项目目录
cd ~
mkdir -p projects
cd projects

# 命令2: 克隆项目
git clone https://github.com/fengyiran-pretty/BiYeSheji.git

# 预期输出:
# Cloning into 'BiYeSheji'...
# remote: Enumerating objects: 123, done.
# remote: Counting objects: 100% (123/123), done.
# ...
# Receiving objects: 100% (123/123), done.

# 命令3: 进入项目
cd BiYeSheji
```

#### 步骤3: 安装依赖

```bash
# 命令: 安装Python包
pip3 install -r requirements.txt

# 预期输出:
# Collecting gradio>=3.0
#   Downloading gradio-...
# ...
# Successfully installed gradio-... numpy-...
```

#### 步骤4: 运行项目

```bash
# 命令: 启动服务器
python3 persistent_server.py

# 预期输出:
# ======================================================================
# 🔬 皮肤病变智能分类系统 - 持久服务器
# ======================================================================
# 🚀 启动Web服务器...
# 📍 本地访问: http://localhost:7860
# ======================================================================
# * Running on local URL:  http://0.0.0.0:7860
```

## 方法二：文件系统复制

### 路径映射关系图

```
┌───────────────────────────────────────────────────────────────┐
│                    Windows ←→ WSL 路径映射                    │
├──────────────────────────────┬────────────────────────────────┤
│         Windows路径          │         WSL路径                │
├──────────────────────────────┼────────────────────────────────┤
│  C:\                         │  /mnt/c/                       │
│  D:\                         │  /mnt/d/                       │
│  C:\Users\                   │  /mnt/c/Users/                 │
│  C:\Users\YourName\          │  /mnt/c/Users/YourName/        │
│  C:\Users\YourName\Documents\│  /mnt/c/Users/YourName/        │
│                              │  Documents/                    │
└──────────────────────────────┴────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│                    WSL ←→ Windows 路径映射                    │
├──────────────────────────────┬────────────────────────────────┤
│          WSL路径             │       Windows路径              │
├──────────────────────────────┼────────────────────────────────┤
│  /home/username/             │  \\wsl$\Ubuntu\home\username\  │
│  ~/projects/                 │  \\wsl$\Ubuntu\home\username\  │
│                              │  projects\                     │
│  ~/projects/BiYeSheji/       │  \\wsl$\Ubuntu\home\username\  │
│                              │  projects\BiYeSheji\           │
└──────────────────────────────┴────────────────────────────────┘
```

### 复制流程图

```

       │
       ↓
┌──────────────────────┐

## 方法四：双向访问（无需复制）

### 访问示意图

#### 从WSL访问Windows文件

```
┌─────────────────────────────────────────────────────────────┐
│                    WSL → Windows                            │
└─────────────────────────────────────────────────────────────┘

WSL终端输入:
┌──────────────────────────────────────────────────────────┐
│ $ cd /mnt/c/Users/YourName/Documents/BiYeSheji           │
│ $ python3 persistent_server.py                           │
└──────────────────────────────────────────────────────────┘

⚠️  注意: 跨文件系统，性能较慢
```

#### 从Windows访问WSL文件

```
┌─────────────────────────────────────────────────────────────┐
│                    Windows → WSL                            │
└─────────────────────────────────────────────────────────────┘

Windows资源管理器地址栏输入:
┌──────────────────────────────────────────────────────────┐
│  \\wsl$\                                                 │
│                                                          │
│  或直接输入完整路径:                                      │
│  \\wsl$\Ubuntu\home\yourusername\projects\BiYeSheji     │
└──────────────────────────────────────────────────────────┘

显示效果:
┌──────────────────────────────────────────────────────────┐
│  📁 网络位置                                              │
│    └─ 📁 wsl$                                            │
│         └─ 📁 Ubuntu                                     │
│              └─ 📁 home                                  │
│                   └─ 📁 yourusername                     │
│                        └─ 📁 projects                    │
│                             └─ 📁 BiYeSheji              │
└──────────────────────────────────────────────────────────┘

## 常见问题图解

### 问题1: 找不到项目文件

```
❌ 错误操作:
┌──────────────────────────────────────┐
│ $ cd BiYeSheji                       │
│ bash: cd: BiYeSheji: No such file... │
└──────────────────────────────────────┘

✅ 正确操作:
┌──────────────────────────────────────┐
│ $ cd ~/projects/BiYeSheji            │
│ $ pwd                                │
│ /home/username/projects/BiYeSheji    │
└──────────────────────────────────────┘
```

### 问题2: Python未安装

```
❌ 错误:
┌──────────────────────────────────────┐
│ $ python3 --version                  │
│ Command 'python3' not found          │
└──────────────────────────────────────┘

✅ 解决:
┌──────────────────────────────────────┐
│ $ sudo apt update                    │
│ $ sudo apt install python3 python3-  │
│   pip -y                             │
│ $ python3 --version                  │
│ Python 3.10.6                        │
└──────────────────────────────────────┘
```

### 问题3: 权限错误

```
❌ 错误:
┌──────────────────────────────────────┐
│ $ ./simple_demo.py                   │
│ Permission denied                    │
└──────────────────────────────────────┘

✅ 解决:
┌──────────────────────────────────────┐
│ $ chmod +x simple_demo.py            │
│ $ python3 simple_demo.py             │
│ 或:                                  │
│ $ find . -name "*.py" -exec \        │
│   chmod 644 {} \;                    │
└──────────────────────────────────────┘
```
