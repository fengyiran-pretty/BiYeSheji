## 关键代码片段详解

### 1. 模型加载 (第58-68行)

```python
# 位置: web_app/app.py 第58-68行
self.model = get_model(model_type, num_classes=num_classes, pretrained=False)

if os.path.exists(model_path):
    checkpoint = torch.load(model_path, map_location=self.device)
    self.model.load_state_dict(checkpoint['model_state_dict'])
    logger.info(f"已加载模型: {model_path}")
else:
    logger.warning(f"模型文件不存在: {model_path}，使用未训练的模型")

self.model.to(self.device)
self.model.eval()
```

**功能**: 
- 创建模型架构
- 加载训练权重
- 转移到GPU/CPU
- 设置为评估模式

### 2. 图像预处理 (第87-100行)

```python
# 位置: web_app/app.py 第87-100行
def preprocess_image(self, image: np.ndarray) -> torch.Tensor:
    # 应用数据增强
    augmented = self.transform(image=image)
    tensor = augmented['image'].unsqueeze(0)
    return tensor
```

**功能**:
- 应用Albumentations变换
- 调整大小、标准化
- 添加批次维度

### 3. 模型推理 (第118-133行)

```python
# 位置: web_app/app.py 第118-133行
# 预处理
input_tensor = self.preprocess_image(image).to(self.device)

# 预测
with torch.no_grad():
    outputs = self.model(input_tensor)
    probabilities = F.softmax(outputs, dim=1)[0]

# 获取预测结果
predicted_idx = outputs.argmax(dim=1).item()
predicted_class = self.class_names[predicted_idx]

# 构建置信度字典
confidences = {
    self.class_names[i]: float(probabilities[i])
    for i in range(len(self.class_names))
}
```

**功能**:
- 无梯度推理（节省内存）
- Softmax计算概率
- 找出最高概率类别
- 构建结果字典

### 4. Grad-CAM可视化 (第136-154行)

```python
# 位置: web_app/app.py 第136-154行
if self.grad_cam:
    try:
        visualization = self.grad_cam.visualize(
            input_tensor,
            original_image,
            target_class=predicted_idx
        )
        visualization = (visualization * 255).astype(np.uint8)
    except Exception as e:
        logger.error(f"生成 Grad-CAM 时出错: {e}")
        visualization = original_image
        if visualization.max() <= 1:
            visualization = (visualization * 255).astype(np.uint8)
else:
    visualization = original_image
    if visualization.max() <= 1:
        visualization = (visualization * 255).astype(np.uint8)
```

**功能**:
- 调用Grad-CAM生成热力图
- 异常处理（失败时返回原图）
- 格式转换为uint8

### 5. Gradio界面配置 (第238-253行)

```python
# 位置: web_app/app.py 第238-253行
interface = gr.Interface(
    fn=classify_image,                                    # 处理函数
    inputs=gr.Image(type="numpy", label="上传皮肤病变图像"),  # 输入
    outputs=[
        gr.Label(num_top_classes=5, label="分类结果与置信度"),  # 输出1
        gr.Image(type="numpy", label="Grad-CAM 可视化")        # 输出2
    ],
    title=title,              # 界面标题
    description=description,  # 使用说明
    article=article,          # 底部文章
    examples=[],              # 示例图像
    allow_flagging="never",   # 禁用标记
    analytics_enabled=False   # 禁用分析
)
```

**Gradio组件**:
- `gr.Image`: 图像上传组件
- `gr.Label`: 分类标签显示
- `gr.Interface`: 界面容器

### 6. 服务器启动 (第284-288行)

```python
# 位置: web_app/app.py 第284-288行
interface.launch(
    server_name="0.0.0.0",    # 监听所有网络接口
    server_port=args.port,     # 端口号（默认7860）
    share=args.share           # 是否创建公共链接

```

**启动参数**:
- `server_name="0.0.0.0"`: 接受所有来源的连接
- `server_port`: 监听端口

## 实际运行示例

### 启动命令

```bash

python web_app/app.py
```

### 访问界面

启动后在终端会看到：

```
Running on local URL:  http://127.0.0.1:7860
Running on public URL: https://xxxxx.gradio.live (如果使用--share)

To create a public link, set `share=True` in `launch()`.
```

在浏览器中打开 `http://localhost:7860` 即可访问界面。

### 使用步骤

1. **打开浏览器** → 访问 http://localhost:7860
2. **上传图像** → 拖拽或点击选择皮肤病变图像
3. **点击Submit** → 等待几秒钟处理
4. **查看结果** → 左侧显示分类和置信度，右侧显示热力图
5. **分析热力图** → 红色区域是模型关注的病变区域
